# Results

| Path | What it is |
|---|---|
| `raw/` | The original per-decision records of every reported run, byte-for-byte, with `SHA256SUMS` and a provenance note |
| `analysis.md` | Intervals, paired comparison, referral comparison and handler classification, generated by `pnpm analyze` from `raw/` |
| `summary.md` | All metrics per router on the test split, generated by `pnpm report --dir results/raw ...` |
| `charts/` | Charts generated from `raw/` by `pnpm charts` |
| `runs/` | Local output of new `pnpm bench` runs (git-ignored); never overwrites `raw/` |
